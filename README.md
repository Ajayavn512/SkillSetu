# SkillSetu — Learn. Practice. Become Job-Ready.

SkillSetu is a free, beginner-friendly practice platform for exploring workplace skills through interactive exercises.

## Skill areas
- **Data entry:** enter sample customer records and check accuracy.
- **Excel & office:** practice totals and spreadsheet formula basics.
- **Graphic design:** customize a poster and export a PNG.
- **Video editing:** plan a simple clip sequence and learn editing choices.
- **Web development:** edit HTML and preview it in a sandboxed frame.
- **Content writing:** draft and review a course description.
- **Customer support:** practice a helpful customer reply.
- **Digital marketing:** create a campaign headline and call to action.

## Run locally
Download or clone this repository and open `index.html` in a modern browser. No build tools are required.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site.

## Privacy and limitations
Practice progress is saved in the browser's local storage on the current device. This version does not include cloud accounts or shared progress across devices. The video task is a workflow exercise, not a full video editor. The platform is educational and does not guarantee employment.

## Built with
HTML, CSS and vanilla JavaScript.
